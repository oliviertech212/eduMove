
# EduMove

EduMove is a centralized platform aimed at revolutionizing student transportation management. The project focuses on creating an efficient, safe, and equitable transport system.

## Objectives

1. To develop a centralized platform for managing student transportation.
2. To calculate optimal routes and travel costs for direct and efficient travel.
3. To notify schools, parents, and transport authorities of student departure and arrival.
4. To aggregate and analyze transport data for better decision-making.
5. To ensure equitable transport access to underserved locations.

## Getting Started

First, run the development server:

```bash
npm install
npm run dev

```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
